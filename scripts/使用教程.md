# 六合彩分析工具 — 详细使用教程

本教程介绍仓库中 `scripts/` 目录下各脚本的用途、安装步骤与使用方法。

---

## 一、文件说明

```
scripts/
├── lhc_analyzer.py      # 核心分析脚本（命令行版）
├── lhc_gui.py           # 图形界面版（Windows / macOS / Linux）
├── lhc_zodiac.py        # 生肖映射与统计分析模块
├── run_gui.bat          # Windows 一键启动 GUI
├── run_gui.sh           # macOS / Linux 终端启动 GUI
├── run_gui.command      # macOS 双击启动（Finder）
├── requirements.txt     # Python 依赖
├── 使用教程.md           # 本文档
└── data/                # 本地缓存目录（运行后自动生成）
    ├── xg6_history.json   # 香港六合彩历史数据
    ├── am6_history.json   # 老澳门六合彩历史数据
    └── nam6_history.json  # 新澳门六合彩历史数据
```

### 各脚本作用

| 文件 | 类型 | 用途 | 适合谁 |
|------|------|------|--------|
| **lhc_analyzer.py** | Python 脚本 | 命令行分析，支持全部参数、JSON 输出、批处理 | 熟悉命令行的用户 |
| **lhc_gui.py** | Python 脚本 | 图形窗口，拖动滑块调整权重，点击按钮分析 | 普通用户（推荐） |
| **run_gui.bat** | 批处理 | Windows 双击启动 GUI | Windows 用户 |
| **run_gui.sh** | Shell 脚本 | macOS / Linux 终端启动 GUI | Mac / Linux 用户 |
| **run_gui.command** | macOS 脚本 | 在 Finder 中双击启动 GUI | macOS 用户 |
| **requirements.txt** | 依赖清单 | 仅需安装 `requests` 库 | 首次使用前安装一次 |

| **lhc_zodiac.py** | Python 模块 | 生肖号码对照、出现比例、下一期生肖参考 | 被 analyzer/GUI 自动调用 |

> **说明**：`lhc_gui.py` 与 `lhc_analyzer.py` 运行后会**自动输出生肖分析**，无需单独运行 `lhc_zodiac.py`。

### 4.2 界面区域说明

```
┌──────────────────┬──────────────────────────────────────────────┐
│  【分析设置】     │  标签页：综合摘要 | 号码分析 | 生肖分析 | 完整报告 │
│  彩种            │                                              │
│  分析期数/近期窗口│  综合摘要：推荐正码、特码、生肖一目了然          │
│  推荐正码数      │  号码分析：正码/特码排名与策略得分              │
│  特码 Top N      │  生肖分析：对照表、出现比例、下一期生肖          │
│  缓存/刷新       │  完整报告：与命令行输出一致                     │

└──────────────────┴──────────────────────────────────────────────┘
```

图形界面已集成**全部功能**，无需再使用命令行：

| 功能 | GUI 位置 |
|------|----------|
| 香港/老澳门/新澳门/全部 | 左侧「彩种」 |
| 号码推荐（正码/特码） | 「综合摘要」「号码分析」 |
| 生肖比例与下一期参考 | 「综合摘要」「生肖分析」 |
| 权重调整 | 左侧 6 个滑块（号码+生肖共用） |
| 导出 JSON | 「导出 JSON」按钮 |
| 复制报告 | 「复制完整报告」按钮 |

### 4.3 操作步骤

1. **选择彩种**：香港 / 老澳门 / 新澳门 / 全部分析
2. **设置分析期数**：
   - 默认 `200` 表示只用最近 200 期
   - 填 `0` 表示使用全部历史数据
3. **设置近期窗口**：默认 `30`，用于计算「近期热度」策略
4. **推荐正码数 / 特码 Top N**：控制推荐号码数量（默认 6 / 3）
5. **调整权重**：拖动 6 个滑块，下方会实时显示归一化后的比例
6. **缓存选项**：
   - 勾选「写入本地缓存」：分析后保存到 `data/` 目录
   - 勾选「强制刷新数据」：忽略缓存，重新从网络拉取
7. 点击 **「开始分析」**，切换右侧标签页查看结果
8. 可选：**导出 JSON** 或 **复制完整报告**

- **综合得分 Top 15**：加权总分排名

## 五、命令行使用（lhc_analyzer.py）

适合需要 JSON 输出、脚本自动化、或远程无界面环境的场景。

### 5.1 基本命令

```powershell
cd D:\developData\PythonPrj\9Y\scripts
```

**香港六合彩（默认）：**

```powershell
python lhc_analyzer.py --cache --refresh
```

**老澳门：**

```powershell
python lhc_analyzer.py -t 老澳门 --cache --refresh
```

**新澳门：**

```powershell
python lhc_analyzer.py -t 新澳门 --cache --refresh
```

**三个彩种一起分析：**

```powershell
python lhc_analyzer.py -t all --cache --refresh --limit 200
```

### 5.2 常用参数一览

| 参数 | 简写 | 默认值 | 说明 |
|------|------|--------|------|
| `--type` | `-t` | `xg6` | 彩种：`xg6` / `am6` / `nam6` / `all`，或中文「香港」「老澳门」「新澳门」 |
| `--limit` | | 无限制 | 只分析最近 N 期，例如 `--limit 200` |
| `--recent` | | `30` | 近期热度统计窗口（期数） |
| `--cache` | | 关闭 | 拉取后写入本地 `data/{彩种}_history.json` |
| `--refresh` | | 关闭 | 忽略缓存，强制从 API 重新下载 |
| `--json` | | 关闭 | 以 JSON 格式输出（便于程序读取） |
| `--top-regular` | | `6` | 推荐正码数量 |
| `--top-special` | | `3` | 展示特码 Top N |
| `--weights` | | 见下文 | 自定义策略权重 |

### 5.3 自定义权重（命令行）

默认权重：

```
全历史频率 20% | 近期热度 25% | 正码强度 20% | 特码强度 10% | 遗漏期数 15% | 出现周期 10%
```

命令行自定义示例（更偏重近期热度）：

```powershell
python lhc_analyzer.py -t 新澳门 --weights "frequency:0.10,recent_hot:0.40,regular_strength:0.20,special_strength:0.10,overdue:0.10,gap_cycle:0.10"
```

权重无需凑满 1.0，程序会自动归一化。

### 5.4 JSON 输出示例

## 五-B、生肖分析功能

分析结果末尾会自动包含生肖统计（CLI 与 GUI 均支持）。

### 输出内容

1. **生肖号码对照表** — 按最新一期所在农历年，展示 12 生肖各自对应哪些号码（本命年 5 个号，其余 4 个号）
2. **生肖历史出现比例** — 各生肖在分析期数内的出现次数、实际比例、理论比例
3. **最新一期生肖分布** — 最新开奖的正码/特码分别属于哪些生肖
4. **下一期生肖参考** — 基于与号码相同的权重策略，给出推荐关注的生肖 Top 5

### 比例说明

| 指标 | 计算方式 |
|------|----------|
| 实际比例 | 该生肖出现次数 ÷ (分析期数 × 7) |
| 理论比例 | 该生肖号码数 ÷ 49（本命年约 10.2%，其余约 8.2%） |

### 映射规则

- 每年农历新年切换后，01 号对应当年本命生肖（如 2026 马年：01=马）
- 02 号为前一个生肖，依次逆推，每 12 个号码循环
- 历史统计时，**每一期按该期开奖日期的农历年**映射号码，确保跨年数据准确

> 生肖推荐同样是历史统计模型输出，不代表下一期真实开奖概率。

## 六、策略权重详解

分析模型对 1–49 每个号码从 6 个维度打分，再按权重加权求和。

| 策略键名 | 中文名 | 含义 | 调高后的效果 |
|----------|--------|------|--------------|
| `frequency` | 全历史频率 | 在所有分析期数里出现越多，分越高 | 更偏向「历史热号」 |
| `recent_hot` | 近期热度 | 在最近 N 期（近期窗口）出现越多，分越高 | 更偏向「最近常出的号」 |
| `regular_strength` | 正码强度 | 作为正码（前 6 个号）出现越多，分越高 | 正码推荐更稳 |
| `special_strength` | 特码强度 | 作为特码（第 7 个号）出现越多，分越高 | 特码推荐更准（统计意义上） |
| `overdue` | 遗漏期数 | 距离上次开出越久，分越高 | 更偏向「长期未出的冷号」 |
| `gap_cycle` | 出现周期 | 平均出现间隔越短，分越高 | 更偏向「有规律出现的号」 |

### 调参建议（娱乐向）

| 目标 | 建议调整 |
|------|----------|
| 追热号 | 提高「近期热度」「全历史频率」 |
| 追冷号 | 提高「遗漏期数」 |
| 专研特码 | 提高「特码强度」 |
| 专研正码 | 提高「正码强度」 |

## 七、本地缓存机制

### 7.1 缓存文件位置

```
scripts/data/
├── xg6_history.json    # 香港
├── am6_history.json    # 老澳门
└── nam6_history.json   # 新澳门
```

### 7.2 何时使用缓存

| 场景 | 建议 |
|------|------|
| 首次使用 | 加 `--cache --refresh` 拉取并保存 |
| 日常分析 | 不加 `--refresh`，直接运行（读本地，速度快） |
| 开奖后更新数据 | 加 `--refresh` 强制更新 |

### 7.3 手动删除缓存

若数据异常，可删除对应 JSON 文件后重新 `--refresh`。

## 八、常见问题

### Q1：`pip install -r requirements.txt` 找不到文件

**原因**：当前目录不对。

| 你所在的目录 | 正确命令 |
|--------------|----------|
| `9Y\scripts` | `pip install -r requirements.txt` |
| `9Y`（根目录） | `pip install -r scripts\requirements.txt` |

### Q2：`'python' 不是内部或外部命令`

Python 未加入 PATH。可改用 `py -3`，或重新安装 Python 并勾选 **Add to PATH**。

### Q3：`No module named 'tkinter'`

图形界面需要 tkinter。

| 系统 | 解决方法 |
|------|----------|
| Windows | 重装 Python，勾选 **tcl/tk and IDLE** |
| macOS (Homebrew) | `brew install python-tk@3.12` |
| macOS (推荐) | 使用 python.org 官方 pkg 安装包 |
| Linux | `sudo apt install python3-tk` |

也可改用命令行版 `lhc_analyzer.py`，不依赖 tkinter。

### Q4：网络请求失败 / 超时

1. 检查网络连接
2. 多试几次
3. 若已有缓存，去掉 `--refresh` 先用本地数据分析

### Q5：`'ls' 不是内部或外部命令`

Windows CMD 用 `dir`，PowerShell 可用 `ls`。

### Q6：推荐号码能直接用来买吗？

**不能作为购彩依据。** 六合彩每期开奖各号码理论概率相等，历史统计无法预测下一期。本工具仅供数据分析与娱乐参考，请理性购彩。
